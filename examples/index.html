    How this page works

    There is no server. The menu is a JSON block on this page. When you press send, the order becomes a ready-made chat message on a wa.me link to the shop's number.

    <link rel="stylesheet" href="order-button.css">
<div id="menu"></div>
<script src="order-button.iife.js"></script>
<script>
  OrderButton.init(menuConfig, { menu: '#menu' });
</script>

    See the README for the menu format, the data attributes for menus you already have, and the Astro component.
